# Auctioneer

A 1.19.2 plugin to allow players to auction items for [Vault](https://github.com/milkbowl/Vault) balance.

## License

Full details can be found in [LICENSE.md](LICENSE.md)

## Installation

1. Be aware of the license terms and ensure you are not in violation of them.
2. Download a compiled jar from the [releases page](https://github.com/AnotherPillow/Auctioneer/releases)
3. Put it in your plugins folder
4. Run the server

## Commands

- `/auctioneer`: Provides info on plugin.
- `/startbidding`: Start an auction on held item.
- `/startbids`: Start an auction on held item.
- `/upauction`: Start an auction on held item.
- `/viewauction [uuid]`: View/bid on an auction.
- `/openauction [uuid]`: View/bid on an auction.
- `/bid [uuid]`: View/bid on an auction.
